# n8n Automation Portfolio: R&D проекты для E-commerce и Gaming

**Product Manager / Automation & AI (R&D)**

Коллекция работающих R&D-прототипов на базе no-code платформы **n8n** и больших языковых моделей (**LLM**). Проекты созданы для автоматизации рутины категорийных менеджеров, защиты маржи и поиска точек роста GMV в игровой индустрии и e-commerce.

---

## 🚀 Мои проекты

### 1. Trend Radar (Автоматизированный радар RMT-трендов)
*   **Задача:** Автоматизировать мониторинг топ-50 игр в Steam для поиска перспективных ниш.
*   **Решение:** Сбор данных из Steam API → расчет динамики онлайна (Growth) на JavaScript → оценка RMT-потенциала через Google Gemini → запись истории в Google Sheets → дайджест в Telegram.
*   **Результат:** Сокращение времени анализа с 4 часов до 5 минут. Отсев «фонового шума» и поиск аномальных всплесков спроса.

### 2. Price Spy (Мониторинг демпинга)
*   **Задача:** Защитить валовую маржу (GM) от резкого снижения цен конкурентами.
*   **Решение:** Парсинг цен конкурентов через API → сравнение с базой (Google Sheets) → расчет дельты → алерт в Telegram при отклонении >5%.
*   **Результат:** Мгновенное реагирование на демпинг без ручного мониторинга.

### 3. News Radar (ИИ-ассистент по новостям)
*   **Задача:** Экономить время на чтении отраслевых новостей.
*   **Решение:** Сбор RSS-лент → фильтрация через LLM (Google Gemini) → дедупликация ссылок через базу памяти → отправка краткого дайджеста.
*   **Результат:** Экономия до 10 часов в неделю, получение только релевантных инсайтов.

### 4. Concierge MVP (Тестирование новых категорий)
*   **Задача:** Проверить спрос на новую категорию товаров без разработки сложного API.
*   **Решение:** Webhook принимает заказ с сайта → пересылка данных селлеру в Telegram для ручной выдачи.
*   **Результат:** Проверка гипотезы за 1 день с нулевыми затратами на IT.

## 💼 Моя роль
*   **Продуктовая аналитика:** Выявление бизнес-болей, формирование гипотез, выбор метрик (GMV, GM, CR).
*   **Архитектура:** Проектирование логики интеграций (Webhooks, REST API, JSON).
*   **Разработка (No-code):** Сборка пайплайнов в n8n, написание кастомного кода на JavaScript (парсинг, расчеты).
*   **AI/LLM:** Разработка промптов, интеграция Google Gemini для оценки данных.

## 🛠 Технологии
*   **Автоматизация:** n8n, Webhooks, REST API.
*   **AI:** Google Gemini, LLM-промптинг.
*   **Код:** JavaScript (Node.js), JSON, HTML/CSS.
*   **Базы данных:** Google Sheets, встроенная память n8n (staticData).
